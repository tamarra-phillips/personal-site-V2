# Tamarra Phillips

This repository contains the personal website for Tamarra Phillips. It is a
static site built with Foundation for Sites, Panini templates, Sass, webpack,
and Gulp.

The site includes:

- A home page and personal portfolio.
- A resume page.
- A generated style guide.
- Responsive styling and optimized production assets.

## Quick Start

1. Install [Docker](https://docs.docker.com/get-docker/).
2. Install [Task](https://taskfile.dev/installation/) `3.x`.
3. From the repository root, start the development server:

   ```sh
   task dev
   ```

4. Open <http://localhost:8000> in a browser.

Task runs the Node.js toolchain in Docker, so Node.js and npm do not need to be
installed on the host.

## Notes

- Generated files are written to `dist/` and are not committed.
- `dist.tar.gz` contains the complete generated site and is also ignored.
- The development server watches source files and serves the generated `dist/`
  directory through BrowserSync.

## Making Changes

Edit the site source, then run the development server while making changes:

```sh
task dev
```

The generated site is served at <http://localhost:8000>. Do not edit files in
`dist/` directly; they are regenerated by the build.

## Local Prerequisites

- [Docker](https://docs.docker.com/get-docker/) for the build toolchain.
- [Task](https://taskfile.dev/installation/) `3.x` for running `Taskfile.yml`.
- A modern browser for viewing the site.

The Taskfile is the source of truth for interacting with the repository. List


## GitHub Actions Build and Release

The repository uses the same Taskfile commands locally and in GitHub Actions:

1. **Pull request workflow ([.github/workflows/main-ci-pr.yml](.github/workflows/main-ci-pr.yml))**:
   - Runs for pull requests targeting `main`.
   - Builds the site with `task build`.
   - Verifies the generated output with `task verify`.

2. **Main CI release workflow ([.github/workflows/main-ci-push.yml](.github/workflows/main-ci-push.yml))**:
   - Runs for pushes to `main`.
   - Packages the complete generated site with `task package`.
   - Compares `dist.tar.gz` with the latest GitHub Release.
   - Publishes a new release only when the generated site changes.
   - Uses daily sequence tags in the format `vYYYY.MM.DD.1`,
     `vYYYY.MM.DD.2`, and so on.

The release asset is `dist.tar.gz`. Extract it to deploy the complete static
site, including all HTML pages, stylesheets, JavaScript, images, and the style
guide.
